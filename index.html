    With the page closed, a phone can tell you. Follow the topic in ntfy, a free notification app. It gets one message, when the block is ready or cannot be built.

    Get it to the watch

    The link below is final. You can put it into the watch settings now: the block shows up under Maps as soon as it is built.

    1. On the iPhone open the Connect IQ app, then My Device, microMAPS, Settings.
    2. Paste the link into the Map host field and save. The field says "leave as it is", but this is the one to use.
    3. On the watch hold UP, open Maps, pick the block and press START.
    4. Keep Garmin Connect open on the phone until the download ends.

    The watch holds one downloaded block. A new one replaces it. Clear the field to bring the full list of areas back.

    What a request does

    A job on GitHub builds the block from OpenStreetMap and terrain data. It needs a minute or two once it starts, and GitHub decides when that is. This page then shows the block as ready, and a phone can get a notice.

    A requested block is published in the open data repository, forever, without any name attached. Anyone can download it. ntfy.sh, which carries the request, and GitHub see an IP address, as any site does.

      How it works

      A block is a square of map, 10 or 20 km on a side. Blocks start every 5 km, so one will sit close to where you need it.

      A block is built once from OpenStreetMap and terrain data, then stays in the open data repository. A dense 20 km block can lose small roads and footways so that it fits. The watch downloads it through Garmin Connect on the phone. After that the map works with no signal.

      Faint outlines on the map are blocks that already exist. Dashes around the current block mean it is not built yet, a solid line means it is ready.

      Privacy

      The app has no server, account or analytics. Your position stays on the watch. Downloads are plain file requests to jsDelivr or GitHub Pages through Garmin Connect, and those services see your IP address and which file was requested.

      This page is static. Map pictures come from OpenStreetMap, the block list from GitHub Pages, and searches go to Nominatim. They see your IP address, and Nominatim sees what you typed. Your position from Locate me and any GPX file stay in this browser.

      A block request sends only the block id to ntfy.sh. The block is then published in the open data repository, forever, without any name attached. While a request waits, the page listens to ntfy.sh for word from the builder, which names block ids and nothing else. ntfy and GitHub see an IP address, as any site does. This browser keeps your requests and the last map position in its local storage.
