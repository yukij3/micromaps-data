microMAPS

Offline maps and routes for Garmin Instinct 3 Solar. No account, no app on the phone besides Garmin's own.

Get a map

On the watch: hold UP, open Maps, pick an area and press START. The watch downloads it through Garmin Connect on the phone, so keep Garmin Connect running and the screen on Maps until it finishes.

Loading the list

Add a route

Turn a GPX file into a route code. The file stays on your phone.

Privacy

The app has no server, account or analytics. Your position stays on the watch. Downloads are plain file requests to jsDelivr or GitHub Pages through Garmin Connect, and those services see your IP address and which file was requested. The route page runs in your browser and sends nothing.
