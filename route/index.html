Add a route to microMAPS

Pick a GPX file. It is read on this phone: the file is not uploaded anywhere.

Paste GPX text instead

  1. Open the Connect IQ Store app on the iPhone, find microMAPS under My Device, tap Settings.
  2. Paste the code into Route code and save.
  3. Open microMAPS on the watch. It shows Route saved.

The watch keeps one route. A new code replaces it. The line on the watch is simplified, so it can run up to the accuracy above from your track.

microMAPS is a map viewer for general orientation, not a certified navigation tool. Maps and data
